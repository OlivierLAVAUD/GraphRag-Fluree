# Source complémentaire : La Tribune — partenariat Microsoft–Mistral (juillet 2026)

Document de synthèse ajouté à la base de connaissances pour l'évaluation RAG.
Source : article de La Tribune cité dans le contexte de test (le texte intégral
de l'article n'est pas dans le jeu de données fourni).

Faits rapportés :
- Brad Smith (Microsoft) a précisé que l'accord annoncé en juillet 2026 ne s'accompagnait d'aucune nouvelle prise de participation de Microsoft dans la startup française Mistral AI.
- Microsoft peut ainsi augmenter rapidement sa capacité de calcul en Europe sans construire lui-même de nouvelles infrastructures, en s'appuyant sur les centres de données et les capacités de Mistral AI en France.
- Rappel du texte principal : Microsoft avait déjà investi dans Mistral AI en 2024 ; l'accord de 2026 reste distinct de cette participation antérieure.
