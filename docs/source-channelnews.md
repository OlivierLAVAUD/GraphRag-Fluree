# Source complémentaire : ChannelNews — coût de l'assistant IA pour la fonction publique

Document de synthèse ajouté à la base de connaissances pour l'évaluation RAG.
Source : article de ChannelNews cité dans le contexte de test (le texte intégral
de l'article n'est pas dans le jeu de données fourni).

Faits rapportés :
- Le coût du déploiement de l'assistant conversationnel alimenté par les modèles de Mistral AI auprès d'un million d'agents de la fonction publique est évalué à 750 000 euros par ChannelNews, tandis que Le Figaro mentionne 700 000 euros.
- Le communiqué officiel (info.gouv.fr) ne publie pas ce chiffre : les médias divergent et aucune source officielle ne tranche l'écart.
