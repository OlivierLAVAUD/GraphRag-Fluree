# Source complémentaire : L'Agence (AA) — transition Palantir vers ChapsVision à la DGSI

Document de synthèse ajouté à la base de connaissances pour l'évaluation RAG.
Source : article de L'Agence (AA) cité dans le contexte de test (le texte
intégral de l'article n'est pas dans le jeu de données fourni).

Faits rapportés :
- Le contrat de long terme liant la DGSI à Palantir (logiciel d'analyse de données, notamment l'outil Gotham), renouvelé fin 2025 pour plusieurs années, demeure pleinement en vigueur.
- La transition vers la solution du français ChapsVision devrait s'étaler sur plusieurs années : il n'y a pas eu de remplacement immédiat ni de rupture du contrat en cours.
